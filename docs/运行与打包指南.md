# 运行与打包指南（Windows，手把手版）

本文档从零开始，教你**怎么把 C-Clear 跑起来**和**怎么打包成 exe 给小白用**。
全程只需要 Windows 自带的 cmd / PowerShell。

---

## 第一部分：安装 Python（只需一次）

1. 打开 https://www.python.org/downloads/ ，点黄色大按钮下载最新版。
2. 运行安装程序，**必须勾选**最底下的 `Add python.exe to PATH`（这步最容易被漏掉）。
3. 点 `Install Now`，等它装完。
4. 验证：按 `Win + R`，输入 `cmd` 回车，在弹出的黑窗口里输入：

   ```
   python --version
   ```

   能显示 `Python 3.x.x` 就是成功了。

> 装好 Python 就够了——本项目的界面库（tkinter）和所有功能都是标准库自带的，
> **不需要再装任何别的软件**。

---

## 第二部分：拿到项目代码

两种方式任选：

**方式 A：用 git 克隆（推荐，能跟着更新）**
```
git clone https://github.com/huiyeo/c-clear.git
cd c-clear
```

**方式 B：下载压缩包**
到 https://github.com/huiyeo/c-clear 点绿色 `Code` 按钮 → `Download ZIP` → 解压 → 进入解压后的文件夹。

---

## 第三部分：创建虚拟环境（只需一次）

虚拟环境 = 给这个项目单独开一个小房间，装包不污染系统。在项目文件夹里打开 cmd：

```
cd c-clear
python -m venv .venv
```

看到生成一个 `.venv` 文件夹就成功了。

---

## 第四部分：运行源码（每次开发时用）

```
.venv\Scripts\activate
```

> 激活成功后，命令行最前面会出现 `(.venv)` 字样，说明你在虚拟环境里。

然后：

```
python main.py
```

窗口弹出来就成功了！

- 「扫 描」= 看看各项目占多少空间
- 「一键清理」= 删除勾选的项目
- 用完输入 `deactivate` 退出虚拟环境

---

## 第五部分：打包成 exe（给小白用）

exe 的意思是：对方**不需要装 Python**，双击就能用。

在激活的虚拟环境里，进入项目文件夹运行：

```
.venv\Scripts\activate
python -m pip install pyinstaller
build.bat
```

或者手动执行打包命令（效果一样）：

```
python -m PyInstaller --noconfirm --clean --onefile --noconsole --uac-admin --name C-Clear main.py
```

打包完成后，exe 在 **`dist\C-Clear.exe`**。把它拷给朋友，双击就能用。

几个参数的意思：
| 参数 | 作用 |
| --- | --- |
| `--onefile` | 打成单个 exe 文件，好拷贝 |
| `--noconsole` | 不弹黑色的命令行窗口 |
| `--uac-admin` | exe 打开时自动申请管理员权限（清理更彻底） |
| `--name C-Clear` | exe 的文件名 |

> `--uac-admin` 在部分精简版系统上可能报错，遇到就删掉这个参数重新打包。

## 常见问题（FAQ）

**Q1：输入 `python` 提示"不是内部或外部命令"**
→ 安装时没勾 `Add python.exe to PATH`。重新运行安装程序，选 `Modify`，勾上 PATH；或搜"python 添加 PATH"跟着改。

**Q2：`activate` 提示"无法加载，因为在此系统上禁止运行脚本"**
→ 这是 PowerShell 的安全策略。改用 cmd 运行（Win+R 输入 cmd 回车再执行），或执行一次：
```
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

**Q3：打包出的 exe 被杀毒软件/Defender 提醒**
→ PyInstaller 打包的程序常被误报（因为它带自解压壳）。这是常见误报，添加信任即可；介意的话就改用 `python main.py` 方式使用。

**Q4：exe 双击没反应 / 清理时很多项显示失败**
→ 确认用右键「以管理员身份运行」；失败的通常是正在被占用的文件（比如正在运行的软件），属正常现象。

**Q5：如何更新到最新版代码？**
→ 如果是 git 克隆的：`git pull`；如果是 ZIP：重新下载覆盖。
